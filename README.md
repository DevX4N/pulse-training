# PULSE Training Club — landing page

Landing page conceitual de uma academia premium (marca fictícia). Página única em HTML/CSS/JS, sem build.

- Abrir localmente: sirva a pasta com qualquer servidor estático e acesse `index.html`.
- Placeholders a trocar antes de usar com cliente real: WhatsApp/telefone `5511900000000`, endereço, e-mail `contato@pulsetraining.com.br`, links das redes sociais (`#`), treinadores e depoimentos.
- O formulário de treino grátis só exibe o estado de sucesso; o envio (CRM/WhatsApp) está marcado com comentário no script.
- Indexação desligada (`noindex` + `robots.txt`) enquanto for projeto de portfólio.
- Fotos: Unsplash (licença Unsplash).
